# DevTask AI

DevTask AI is an AI-powered project management assistant that helps users manage projects, tasks, bugs, and sprint notes.

## Planned Features

- User login
- Project creation
- Task and bug tracking
- Kanban board
- AI-generated user stories
- AI-generated acceptance criteria
- AI-generated test cases
- Sprint summary generator

## Tech Stack

- Frontend: Next.js, React, Tailwind CSS
- Backend: FastAPI
- Database: Supabase PostgreSQL
- Auth: Supabase Auth
- AI: Groq or Gemini API
- Deployment: Vercel, Render, Supabase
